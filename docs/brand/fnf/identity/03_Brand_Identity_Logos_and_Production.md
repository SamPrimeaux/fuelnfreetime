## Manufacturer-ready means more than SVG

The logo must survive the **actual size and method**. Different production methods need different vendor-prepared exports.

### Screen print / heat transfer / DTF

- Vector paths; solid inks; readable spaces and contours.
- Color specifications agreed with the print vendor; no accidental automatic recoloring.
- Exact art dimensions on the blank and accurate placement measured from collar/seam.
- Vendor proof of fine details and trapping; physical sample before full run.
- Note whether screen print, transfer, or another process is used (don't conflate them).

### Embroidery / woven patch

- Use a simplified, readable one-/few-color art master; avoid tiny counters and narrow gaps.
- Vendor digitizes the design for the chosen machine, fabric and dimensions; a generic SVG is not a DST/PES stitch program.
- Specify cap profile, backing, patch size, thread colors, border finish, backing and attachment method.
- Order one test and review lettering shape, thread gaps, corner density, puckering and small details.

### Laser engraving / etch / stamp

- Give vendor single-color positive and reversed negative silhouettes, with actual dimensions and desired material finish.
- Fine line work and tiny negative cutouts can disappear; ask vendor for minimum supported gap/stroke at intended physical size.
- A black raster proof can *look* perfect but engrave poorly; use material test coupons and inspect on real product.
- Check whether the process removes coating, changes metal color or produces a contrasting mark; avoid invented previews.

### Sticker / decal / vinyl

- Correct contour-cut path, bleed if requested, margin around shield, color and finish specs.
- For one-color vinyl, use an actual cuttable silhouette rather than assuming an intricate stroke design weeds cleanly.

## What to polish in the logo master

**Preserve:** The pointed shield profile, serif letterforms, narrow ampersand, badge proportions and recognizable silhouette.  
**Refine:** Distressed grain, aliasing, inconsistent border weight, undersized gaps, awkward contour wobble, transparency and redundant effects.  
**Avoid:** Generic replacement fonts, slightly misspelled characters, unrealistic chrome/metal gradients in vendor source art, over-thinning the letters.
