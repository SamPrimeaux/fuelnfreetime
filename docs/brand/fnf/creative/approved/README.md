# Approved Usage Register

This location records **approval decisions**, not alternate copies of source media. The actual master stays in its versioned source location (Git artwork folder or FNF media library).

Create one small Markdown review record per approved version, referencing the [asset template](../templates/ASSET_RECORD.md). Include reviewer, date, exact source file/ID/hash, approved application and any limitations.

**Approval scopes are different:**

- `creative-only`: concept selected; **not** manufacturing or publishing permission;
- `web-editorial`: suitable for specified website/story use;
- `product-listing`: accurate depiction of a real verified product;
- `manufacturing-[process]`: exact treatment/sizes approved after vendor proof;
- `social/creator`: usage rights confirmed for specific content;
- `live-published`: verified URL or underlying CMS entry.

No approvals have been recorded in this folder yet. The reconstructed F&FT logo masters remain **manufacturer-review** and should not be promoted automatically.
