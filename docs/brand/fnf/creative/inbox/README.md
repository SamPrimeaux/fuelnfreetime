# Creative Inbox

**Purpose:** quick intake, not a graveyard of unattached JPEGs.

For a new idea, save or link its **original** first. Then copy [the asset template](../templates/ASSET_RECORD.md) and record it in the appropriate category once sorted.

### Intake checklist

- [ ] Where did this come from (Justin photo, original illustrator, vendor, AI-generated concept, external reference)?
- [ ] Is the original still preserved?
- [ ] Is the content ours, licensed, or reference-only?
- [ ] Is it a real physical product, an artwork concept, or a publicity idea?
- [ ] What should Justin evaluate (style, wording, garment placement, color, price)?
- [ ] Which collection/project might it belong to?
- [ ] Where is the actual file (existing FNF media asset ID / album, or explicit archive path)?

**Naming example:** `fnf-2026-10-06-smoke-show-concept-a`. Avoid `final-v8-reallyfinal.png`.

Move classified records to [collection concepts](../../collections/concepts/README.md), [product photography](../../products/photography/README.md), [identity](../../identity/artwork/v1/README.md), or [campaigns](../../campaigns/creative/README.md). Do not move/delete originals just because the review record moves.
