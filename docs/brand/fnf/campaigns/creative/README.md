Use [Asset Record](../../creative/templates/ASSET_RECORD.md) for each incoming batch and link all scenes/edits back to raw recordings. Track who filmed it, who appears, permissions, date and publication scope. Creator collaborations are **unconfirmed** until the people involved agree.
