# Physical Products — Photography & Presentation

This category tracks **real sample/product evidence**, improved catalog imagery, and approval for customer-facing presentation.

## Known sample categories (verify details with Justin)

- F&FT badge shirt / front chest placement
- Hourglass-themed shirt / back graphic
- F&FT caps with badge patches
- F&FT tumbler

These are observed references from the creative handoff, **not** verified available inventory or a published product catalog. See [product brief](../../collections/04_Collections_and_Real_Products.md).

## Recommended per-product photo set

1. Unedited original sample photos (front, back, sides).
2. Neutral studio listing presentation matching actual garment/product colors, material, shape, graphics and placement.
3. Detail crops of patches, seams, texture, printed artwork, closures/engraving.
4. Clearly labeled lifestyle/editorial images.
5. Manufacturer proof or approved final production image, if different from the sample.

## Asset record requirements

Use [Asset Record](../../creative/templates/ASSET_RECORD.md). Include actual product/variant IDs only when verified, material/fabric source, photographer/source, image transformation, print-location fidelity review, and image usage rights.

Retouches must not invent logos, lettering, colorways, endorsements or construction details. AI campaign renders are concept visuals until matched against the actual product. Product-detail pictures and descriptions must reflect what the customer receives.

**Storage boundary:** originals, front/back, details, and optimized deliveries belong in FNF's existing Content/media library with product relationships; this Markdown category indexes decisions and references. Do not build a parallel image upload API here.
