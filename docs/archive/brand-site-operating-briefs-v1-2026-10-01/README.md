# Brand + Site Operating Briefs v1

Working audit/strategy package for:

- AgentSam SDK — productization/remaster lane
- Fuel & Free Time — launch-polish lane

State labels used throughout:

- **CONFIRMED** — supported by current public surface, supplied screenshots, or explicit project direction.
- **PROPOSED** — recommended direction awaiting owner/client approval.
- **TBD** — required information not yet resolved.
- **ASPIRATIONAL** — useful future direction, not a current capability.
- **REJECT / PARK** — should not consume current launch work.

The package is intentionally outcome-first. It separates brand truth, page purpose, user journeys,
admin operations, launch blockers, reusable prebuild extraction, and future ideas instead of judging
a project only by whether a URL is live.
